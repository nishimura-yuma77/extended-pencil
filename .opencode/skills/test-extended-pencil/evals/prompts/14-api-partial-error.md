# ケース14: 部分的に確定したエラー契約

以下をエージェントへの初回指示文として渡す。

> `$extended-pencil` を使い、`docs/orders-api.md` に注文状態更新APIの設計を書いてください。`PATCH /v1/orders/{id}` は管理者だけが実行できます。Pathの文字列 `id` とBodyの文字列 `status` が必須です。成功時は更新した注文IDを返します。指定注文が存在しない場合、HTTPステータスは404、アプリケーションのエラーコードは `ORDER_NOT_FOUND` です。ただしエラーレスポンスの構造・文言は未決です。古いクライアントとの互換性についてもまだ判断していません。
