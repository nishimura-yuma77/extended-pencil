# ケース11: URLの有無・クエリ・初期表示

以下をエージェントへの初回指示文として渡す。

> `$extended-pencil` を使い、`docs/report-screens.md` にレポート一覧画面と絞り込みダイアログの画面設計を書いてください。一覧画面のURLは `/reports` で、絞り込みダイアログにはURLがありません。一覧画面で絞り込みボタンを押すとダイアログが開きます。一覧画面の `page` クエリは整数・任意で、省略時は1です。初回表示前と再表示時には `src/server/reports.ts` の `listReports` を呼び、`page` を渡してレポートのタイトル一覧を受け取ります。一覧画面のデザインは `https://design.example.com/reports` にあります。絞り込みに使える項目はまだ決まっていません。
