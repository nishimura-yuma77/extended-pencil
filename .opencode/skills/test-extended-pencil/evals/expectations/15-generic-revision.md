# ケース15: 期待結果と評価項目

成果物: `docs/support-operations.md`。初回と追加回答後をそれぞれ保存し、表の各行を1点として採点する。

| 確認先 | 期待する内容 |
| --- | --- |
| 初回 → 確定事項 | 担当者がサポートポータルで問い合わせ一覧を閲覧できる。受付時間は確定していない。 |
| 初回 → AIの推測の表 | 共通の3列で旧運用メモを出典とする24時間受付が現行採用未確認の推測として記載されている。 |
| 初回 → 検討事項の表 | 共通の4列で、現行の受付時間を人間に確認する質問がある。 |
| 初回 → 対話 | 原則1件で現行の受付時間を具体的に尋ねる。 |
| 追加回答後 → 確定事項 | 受付時間が平日9時～17時に更新され、担当者による問い合わせのアーカイブを記載している。 |
| 追加回答後 → 文書全体 | 却下された24時間受付を確定事項や有効な推測として残していない。 |
| 追加回答後 → 検討事項の表 | 解決済みの受付時間を残さず、アーカイブ後の保管期間を新しい具体的な質問にしている。 |
| 追加回答後 → 確定事項 | アーカイブ後の保管期間を確定値として作り足していない。 |
| 追加回答後 → 対話 | 原則1件で残る保管期間の判断を尋ねる。 |
